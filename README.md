# NightDesk

NightDesk is a small web project built around a simple idea: keeping useful everyday tools on one page instead of opening several different apps or tabs.

The dashboard combines a clock, search, notes, a to-do list, a focus timer, and quick links. The layout is flexible, so widgets can be moved, resized, or hidden depending on what is needed.

## What can you do with it?

- Search Google directly from the dashboard.
- Check the current time and date, with optional seconds and a choice of 12-hour or 24-hour format.
- Switch between dark and light themes.
- Use the interface in English or Czech.
- Keep quick links, notes, and to-do items in one place.
- Use the focus timer while working or studying.
- Rearrange widgets and choose which ones remain visible.

Your settings and dashboard data are saved in the browser, so they remain available when you return.

## How it was made

NightDesk uses plain HTML, CSS, and JavaScript. There is no framework or additional installation required to run the project.

Building it involved more than putting elements on a page. I worked on making the widgets interactive, keeping their positions and sizes, handling user preferences, and making sure the different settings work together.

AI tools were used as a source of assistance during development, including debugging and reviewing code.

## Run it locally

Download or clone the repository and open `index.html` in a modern browser with JavaScript enabled.

That's all you need to get started.
