# NightDesk

A customizable productivity dashboard built with HTML, CSS, and JavaScript.

NightDesk brings everyday tools into one workspace, with a focus on flexibility, simplicity, and personalization.

## Features

- Google Search
- Live clock and date
- Dark and light themes
- English and Czech language settings
- 12-hour and 24-hour time formats
- Optional seconds display
- Quick Links
- To-Do list
- Focus Timer
- Notes
- Draggable and resizable widgets
- Widget visibility controls
- Persistent settings and user data

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Make sure JavaScript is enabled.

## Development

NightDesk was developed as a hands-on web development project. The development process involved experimenting with layout, styling, widget interactions, and persistent settings.

AI assistance was used during development for technical questions, debugging, and code improvements.
